# Semi-Secret Wars

Semi-Secret Wars is a minimalist Incremental Auto Battler presented as the pages of a child's comic notebook. Players assemble a hero roster, assign pre-battle priorities, and watch battles resolve automatically — every battle contributes to permanent hero progression.

## Current Project Status

Prototype / Vertical Slice — documentation scaffold established, no gameplay scenes built yet.

## Engine Version

Godot 4.7-stable (GL Compatibility renderer)
