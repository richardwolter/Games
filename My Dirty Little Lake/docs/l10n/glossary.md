# My Dirty Little Lake — glossary

The game's fixed terms, from Richard's final Portuguese (2026-10-10). Every language keeps one
word per concept, used the same way on every screen. The English column is the English the
game will use; each language's own column is written by its translator into
`tools/l10n_work/glossary_<locale>.json` and checked by its reviewer.

## Upgrades (the shop's rows). Names, short, capitalised as a label

| PT (source) | EN | Meaning |
|---|---|---|
| Tamanho | Size | how big the net's ring is |
| Força | Strength | the heaviest weight tier the net can lift. **The dogs' row has the same word** (Richard's call): the heaviest tier the dogs can carry |
| Alcance | Range | how far the net can be thrown |
| Recolha | Reel | how fast the net comes back |
| Captura | Catch | how many pieces one cast brings home |
| Rapidez | Speed | how fast the boats sail |
| Carrega | Capacity | how many pieces a boat holds |
| Carga | Loading | how fast a boat loads and unloads |
| Barcos | Boats | one more boat (the fleet) |
| Matilha | Pack | one more dog |
| Busca | Fetch | how many pieces a dog brings a trip |
| Vontade | Keenness | how little a dog rests between trips |
| $ Bônus | $ Bonus | one pier pays extra, moving every 30 s |
| Pombos | Pigeons | what a netted pigeon pays |
| Sorte | Luck | the chance of a lucky cast |
| Dobro | Double cast | the chance of a second net |
| Mangueira | Hose | the wash room's hose |
